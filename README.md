# Chalk Tweaks

A small add-on for [Chalk](https://modrinth.com/mod/chalk) on Fabric, Minecraft 26.3.

- **Chalk lasts 4 times longer.** Every chalk stick, normal and glow, in every color, gets 256 marks instead of 64.
- **Hand-drawn arrows.** The marks are redrawn as chalk strokes that read as real arrows. The arrows come as a built-in resource pack called "Hand-drawn Chalk Arrows", turned on by default. You can turn it off in Options > Resource Packs.

Install it on both the server and the clients. The server decides how long chalk lasts; clients need it so the durability bar matches.

## Requirements

- Minecraft 26.3, Fabric Loader 0.19.5 or newer
- Fabric API
- Chalk
